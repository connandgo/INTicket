# MVP 공연 포스터

외부 공연 이미지의 저작권과 링크 만료 문제를 피하기 위해 OpenAI 내장 이미지 생성 도구로 만든 오리지널 발표용 자산입니다. 이미지에는 공연명, 로고, 실존 배우나 기존 공연 포스터 요소를 넣지 않았습니다.

| 공연 ID | 파일 | 생성 콘셉트 |
|---:|---|---|
| 1 | `course-1-phantom.webp` | 오페라 극장, 가면, 장미 |
| 2 | `course-2-waiting.webp` | 빈 무대, 나무, 벤치, 기다리는 실루엣 |
| 3 | `course-3-resurrection.webp` | 대편성 오케스트라와 합창, 떠오르는 빛 |
| 4 | `course-4-first-light.webp` | 일출 조명과 현대적인 아레나 무대 |
| 5 | `course-5-barricade.webp` | 19세기 파리풍 거리, 바리케이드와 등불 |
| 6 | `course-6-midsummer.webp` | 달빛 숲 무대와 춤추는 실루엣 |
| 7 | `course-7-piano.webp` | 그랜드피아노와 다섯 줄기의 조명 아치 |

원본 생성물은 세로 3:4 구성이며, 웹 배포용 파일은 `720x960`, WebP 품질 82로 최적화했습니다. `PosterArt.vue`가 MVP 시드 ID 1~7을 이 파일들과 연결하고, 그 밖의 공연에는 기존 그라데이션 포스터를 표시합니다.
